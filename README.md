# Begehungsprotokoll

iPhone-Web-App für digitale Begehungsprotokolle bei Trassenbegehungen:
Trasse per GPS/Karte/Sprache erfassen, Fotos und Notizen zuordnen, PDF-Protokoll mit eigenem
Briefbogen erzeugen und über iOS teilen.

* Technische Doku: [docs/ARCHITEKTUR.md](docs/ARCHITEKTUR.md)
* Start: `npm install`, `npm run dev` · Build: `npm run build` → Ordner `dist/` veröffentlichen (HTTPS)
